# College Placement Management System (CPMS)

A centralized backend system to manage college placements — replacing scattered WhatsApp groups, emails, and notice boards with a structured, API-driven platform.

## 🚧 Project Status: In Progress

This project is being actively built, module by module. Core backend logic is functional; frontend, authentication, and advanced features are in development.

## ✅ Completed So Far

- **Student Module** — Register, view, update, delete student profiles (name, branch, CGPA, skills)
- **Company Module** — Add companies with role, package, location, eligibility criteria
- **Application Module** — Students apply to companies with **automatic eligibility checking** (CGPA + branch validation)
- **Interview Module** — Schedule and manage interview details (date, time, venue)
- **Result Module** — Publish and track final selection results

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, Spring Data JPA, Spring Security
- **Database:** MySQL
- **Testing:** Postman
- **Build Tool:** Maven
